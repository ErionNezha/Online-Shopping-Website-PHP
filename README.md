# Online Shopping Website

Dyqan online me PHP/MySQL — katalog kamerash, orash e këmishash me shportë blerjesh. Demo-ja është simulim web i storefront-it me produktet reale nga databaza.

## ▶️ Live Demo
Hap `demo/index.html` në browser — ose shiko Live Demo-n në GitHub Pages.
